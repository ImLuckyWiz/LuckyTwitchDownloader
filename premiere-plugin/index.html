A real VOD keeps only about 10%, so deleting around 90% is normal and the default limit is 99%. The padding and merge settings above must be the ones you cut with, otherwise pieces are only partly inside a clip and the delete refuses.
Clips that touch or overlap are one clip: padding never adds a cut between them. Cutting needs an empty video track and an empty audio track above the clip. Do it all makes one backup per run; the Cut buttons skip theirs when one was made in the last 30 minutes.
Settings are remembered. One undo step (Ctrl/Cmd+Z) removes what a marker import added; a cut is many steps, so keep the backup on.

Probes: they only read. Press the first one, then Copy log and send it.
Gap plan is a dry run for the delete: how every piece on the timeline is classified (keep / gap / uncertain) and whether the safety guard lets it through. Cut plan is a dry run: it shows where the clips would be cut on the target clip (needs a loaded file). Nothing is changed.
Experiments: these change the project. Ctrl+Z undoes them.
Test ripple delete: run it on a COPY of the project, on a timeline already cut into pieces (V1 + A1, empty V2 / A2 above). It removes pieces in several ways, measures what Premiere did and prints the answers at the end of the log. Press it twice (the first press only arms it). Many undo steps.
Test split (clone + trim) is the new method: it needs an EMPTY video track (and audio track) above your clip. Test cut at playhead: put the playhead in the middle of your clip first. It tries to split the clip there (video and audio); up to 3 undo steps.
Test keep-linked clone: run it on a COPY of the project, on a clip that has never been cut (its video and audio still linked), with the playhead inside it and an empty V and A track above. It makes ONE copy of the clip with alignToVideo on, then compares what is selected. Click the copy in the timeline: if its audio lights up with it, the link survives. Ctrl+Z (one step) removes it.
